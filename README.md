# Ladomi

Ladomi — iOS-приложение для спокойного отслеживания дня: привычек, разовых событий, настроения, прогресса и отдельного стоп-листа для действий, которых пользователь хочет избегать.

Приложение построено вокруг короткой ежедневной отметки. Пользователь добавляет привычки и события, отмечает выполнение, смотрит день в календаре и через аналитику понимает, что помогает или мешает стабильности.

## Что умеет приложение

- Отслеживает регулярные привычки с расписанием по дням недели.
- Отслеживает разовые события, запланированные на выбранную дату.
- Ведёт отдельный стоп-лист для нежелательных действий: курения, алкоголя, вредной еды и других личных ограничений.
- Показывает прогресс дня на главном экране в виде цветных карточек.
- Поддерживает категории для привычек и событий.
- Позволяет закреплять важные планы над основным списком.
- Даёт поиск и фильтры по привычкам и событиям.
- Показывает календарь с настроением, выполненными планами и срывами из стоп-листа.
- Строит аналитику по выполнению, нагрузке, настроению, лучшему дню недели и срывам.
- Хранит завершённые привычки и события в архиве.
- Поддерживает виджет с прогрессом на сегодня.
- Поддерживает русскую и английскую локализацию.
- Поддерживает адаптивный интерфейс iPad в портретной и альбомной ориентациях.

## Основные экраны

### Онбординг

При первом запуске открывается онбординг из двух экранов. Он показывает идею приложения: собрать день из привычек и событий, а потом смотреть результат через календарь, настроение, напоминания и аналитику.

Кнопка на первом экране ведёт на второй экран онбординга. Кнопка на последнем экране открывает приложение.

### Мой день

Главный экран работает в двух режимах:

- `Планы` — привычки и события.
- `Стоп-лист` — действия, которых пользователь хочет избегать.

В режиме `Планы` карточки сгруппированы по категориям. Карточка показывает эмоджи, название, счётчик выполнений, цвет и кнопку для отметки выполнения на выбранный день.

В режиме `Стоп-лист` категории скрыты. Карточки показывают количество дней без срыва. Отметка пункта стоп-листа означает, что в выбранный день был срыв.

Дата на главном экране форматируется по языку приложения. Кнопка `+` сразу открывает экран создания.

### iPad

На iPad интерфейс адаптируется к ориентации устройства:

- в портретной ориентации основная навигация расположена внизу;
- в альбомной ориентации используется боковое меню с контекстной кнопкой `Новый план` или `Новый стоп-пункт`;
- карточки привычек и событий перестраиваются в сетку и сохраняют общий левый край с заголовками категорий;
- формы создания, пустые состояния, календарь и аналитика учитывают доступную область экрана.

### Создание и редактирование

Экран создания поддерживает три типа:

- привычка;
- событие;
- пункт стоп-листа.

Пользователь может настроить:

- название;
- тип через segmented control;
- категорию для привычек и событий;
- расписание по дням недели для привычек;
- дату для события;
- время напоминания для привычек и событий;
- эмоджи;
- цвет.

Для пунктов стоп-листа категории и напоминания не используются.

### Календарь

Календарь показывает месяц и детальный блок выбранного дня.

В ячейках календаря могут отображаться:

- эмоджи настроения;
- точки выполненных привычек и событий;
- отдельная точка срыва из стоп-листа;
- компактное состояние, если точек слишком много.

В детальном блоке дня отображаются:

- выполненные привычки;
- выполненные события;
- общее количество выполненного;
- срывы;
- выбор настроения;
- список выполненных планов и записанных срывов за день.

Для будущих дней настроение недоступно.

### Аналитика

Аналитика считает привычки и события отдельно от стоп-листа. Пункты стоп-листа не попадают в основную статистику, но срывы отображаются отдельным инсайтом.

Экран показывает:

- количество дней в анализе;
- количество дней с отмеченным настроением;
- общий прогресс;
- срывы;
- влияние настроения;
- влияние нагрузки дня;
- лучший день недели;
- совет на основе текущих данных.

Экран аналитики скроллится целиком вместе с заголовком.

### Архив

Архив хранит привычки и события, которые пользователь убрал с главного экрана. Для каждого пункта показывается дата архивации и короткая сводка по выполнению. Его можно вернуть из архива.

### Виджет

Виджет показывает прогресс привычек и событий на сегодня. Пункты стоп-листа в прогресс виджета не входят.

Поддерживаемые размеры:

- small;
- medium;
- accessory circular;
- accessory rectangular;
- accessory inline.

Текст виджета локализован на русский и английский.

## Данные и хранение

Ladomi хранит данные локально:

- привычки, события, категории и записи выполнения хранятся в Core Data;
- настроение, закрепления, переносы планов, состояние онбординга и снапшоты виджета хранятся в local user defaults;
- виджет читает общий снапшот через app group.

Синхронизация через iCloud в текущей версии не реализована.

## Локализация

В приложении есть:

- русская локализация;
- английская локализация.

Локализованы основное приложение, стоп-лист, календарь, аналитика, виджет и launch screen.

- UIKit
- SwiftUI для WidgetKit
- Core Data
- WidgetKit

## Структура проекта

```text
Ladomi/
  Ladomi/                 основной iOS target
  LadomiTodayWidget/      widget extension
  LadomiTests/            тесты
  Ladomi.xcodeproj        Xcode project
  Ladomi.xcworkspace      Xcode workspace
```

## Требования

- Xcode 17 или новее
- iOS 13.4+ для основного приложения
- iOS 16.0+ для widget extension
- Swift 5
- iPhone и iPad; на iPad поддерживаются портретная и альбомная ориентации

## Сборка

Открыть проект в Xcode:

```bash
open Ladomi.xcodeproj
```

Или собрать из терминала:

```bash
xcodebuild \
  -project Ladomi.xcodeproj \
  -scheme Ladomi \
  -sdk iphonesimulator \
  -destination 'generic/platform=iOS Simulator' \
  CODE_SIGNING_ALLOWED=NO \
  build
```
